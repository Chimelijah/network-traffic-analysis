# Wireshark Network Simulation

## 🛠️ Tech Stack
**Technologies:** `Mininet, CyberOps VM, Wireshark, Linux namespaces`

## 📖 Project Overview
Configured a simulated Mininet network to capture and dissect ICMP data between virtualized hosts and cross-subnet gateways.

## 🚀 Key Learnings
* Configuration and deployment of `Mininet, CyberOps VM, Wireshark, Linux namespaces` in a production-like environment.
* Deep-dive analysis of system logs and network traffic.
* Documentation of technical workflows for architectural clarity.
