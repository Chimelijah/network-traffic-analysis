# HTTP vs HTTPS Traffic Analysis

## 🛠️ Tech Stack
**Technologies:** `tcpdump, Wireshark, PCAP, TLS`

## 📖 Project Overview
Utilized tcpdump to capture live web traffic, exporting PCAP files into Wireshark to contrast unencrypted HTTP credentials with TLS-encrypted HTTPS traffic.

## 🚀 Key Learnings
* Configuration and deployment of `tcpdump, Wireshark, PCAP, TLS` in a production-like environment.
* Deep-dive analysis of system logs and network traffic.
* Documentation of technical workflows for architectural clarity.
