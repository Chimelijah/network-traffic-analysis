# Identifying Packet Flows Using Cisco Packet Tracer

## 🛠️ Tech Stack
**Technologies:** `Cisco Packet Tracer, EIGRP, NAT, ICMP`

## 📖 Project Overview
Emulated WAN topologies to analyze dynamic routing (EIGRP) and NAT while tracking packet traversal in Simulation Mode.

## 🚀 Key Learnings
* Configuration and deployment of `Cisco Packet Tracer, EIGRP, NAT, ICMP` in a production-like environment.
* Deep-dive analysis of system logs and network traffic.
* Documentation of technical workflows for architectural clarity.
