# Examining Ethernet Frames

## 🛠️ Tech Stack
**Technologies:** `Wireshark, Ethernet II, MAC Addressing`

## 📖 Project Overview
Captured local traffic to dissect Ethernet II frame headers, observing MAC address swapping and analyzing the OSI Data Link layer.

## 🚀 Key Learnings
* Configuration and deployment of `Wireshark, Ethernet II, MAC Addressing` in a production-like environment.
* Deep-dive analysis of system logs and network traffic.
* Documentation of technical workflows for architectural clarity.
