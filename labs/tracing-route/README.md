# Global Route Tracing & Analysis

## 🛠️ Tech Stack
**Technologies:** `Ping, Tracert, DNS, ICMP`

## 📖 Project Overview
Investigated global internet pathways by utilizing CLI tools to understand packet traversal, FQDN resolution, and latency metrics.

## 🚀 Key Learnings
* Configuration and deployment of `Ping, Tracert, DNS, ICMP` in a production-like environment.
* Deep-dive analysis of system logs and network traffic.
* Documentation of technical workflows for architectural clarity.
